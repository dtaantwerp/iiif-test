IIIF on GitHub Pages

Text as Data 2026–27 · a test with the staff copies W, X and G of the Class Tradition

GitHub Pages can only serve files that exist. A IIIF image server computes every image you ask for: any region, size, rotation and quality. Here a small script in your browser (a service worker) plays the server: it loads the full scan once and computes the rest. Image server: starting…

Try an address

The Image API address has a fixed order: {identifier}/{region}/{size}/{rotation}/{quality}.{format}. Change a part, and see what comes back.

A viewer

The manifest lists the six pages and points to their image server. Open it in Mirador: every tile you see while zooming is computed by the service worker.

What this cannot do

The server only exists in a browser that has visited this site. curl, Python's requests, Transkribus or a viewer on another website get a "not found": for them there is no image server here, only files.
